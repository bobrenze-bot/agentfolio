Implementation Notes

TrustPanel.astro

Main component with uncertainty visualization, plain language explanation, and factor breakdown.

  • Score + confidence interval display
  • Probability distribution visualization
  • Per-factor uncertainty disclosure
  • Integrated limitations warning

LimitationsWarning.astro

Standalone component for limitations disclosure in various contexts.

  • Full, compact, and inline variants
  • Configurable context text
  • Accessible alert/role attributes

confidenceService.ts

Statistical confidence interval calculation with multiple methods.

  • t-distribution for small samples
  • Normal approximation for large samples
  • Bootstrap method for robustness
  • Weighted observation support

explanationGenerator.ts

Plain language explanation generation following MESSAGING.md patterns.

  • Context-aware explanations
  • Screen reader versions
  • Comparison and trend support
  • Action recommendations
